# AI Agent Instructions

## What is this project?

This is a website for providing potential employers information about myself (Nathan Myers) as well as hosting projects.

## How to make changes

- On fresh checkout, be sure to install dependencies (`npm i`)
- Run tests with `npm run test`
- `GameOfLife.tsx` is intended to function as a fixed background. Extra content should flow on top of that.
- New changes should be done inside of a branch, which the user will review before merging
